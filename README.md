## ✨ Overview

This repository contains the source for my personal portfolio site — a single-page site introducing who I am, the projects I've built, and how to get in touch. Built with plain HTML/CSS for fast loading and easy deployment on any static host (GitHub Pages, Vercel, Netlify).

## 📂 Project Structure

```
portfolio-shreyas/
└── index.html    # Full single-page portfolio (HTML + inline CSS/JS)
```

## 🚀 Deploying

### GitHub Pages
1. Go to **Settings → Pages**
2. Set source to the `main` branch, root directory
3. Your site will be live at `https://shareyaschavan-pixel.github.io/portfolio-shreyas/`

### Vercel / Netlify
Import this repository directly — no build command needed since it's static HTML.

## 🛠️ Tech Stack
